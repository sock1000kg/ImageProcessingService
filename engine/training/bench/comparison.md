# Accuracy comparison

Generated by `compare.py` on the benchmark set (`labels-max.jsonl`: 3,726 images, faces from WIDER val, plates from the VN set). Run folders: `bench/<name>/` (`accuracy.md` there = full breakdown of that run at threshold 0.15, deface 0.2). Training records of each model: `results/<experiment>/<run>/`.

**Privacy** = share of faces (plates) at least 70 % covered by the blurred boxes; **P / R / F1** at IoU >= 0.5. Models are compared at the **same face precision**, since a threshold means something different for each model. Our detections are saved from confidence 0.05 (the engine's floor), so a model whose precision is already above the target there is shown at 0.05 (noted).
